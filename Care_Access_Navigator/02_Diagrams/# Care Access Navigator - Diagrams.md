# Care Access Navigator - Diagrams

## Purpose

This folder stores the architecture and workflow diagrams created for the Care Access Navigator project.

## Folder Structure

- `01_Architecture` - Stores system and IAM architecture diagrams.
- `02_Workflows` - Stores IAM, access, and security workflow diagrams.

## Architecture Diagrams

Examples:

- High-Level Architecture
- IAM Architecture
- Keycloak Architecture
- Application and Logging Flow

## Workflow Diagrams

Examples:

- Joiner / Mover / Leaver Workflow
- Access Request Workflow
- Access Review Workflow
- Incident Response Workflow

## Naming Standard

Standard Using:

`CAN_DGM_<Description>_v<Version>`

Examples:

- `CAN_DGM_High_Level_Architecture_v0.1`
- `CAN_DGM_Access_Request_Workflow_v0.1`

## Notes
  Remember to:
- Use only synthetic/non-production information.
- Do not include passwords, secrets, or credentials.
- Keep diagrams clear and easy to understand.
- Portfolio diagrams should be sanitized before publishing.
