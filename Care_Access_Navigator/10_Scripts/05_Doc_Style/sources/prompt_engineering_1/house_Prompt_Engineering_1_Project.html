1. Tokenization and Data Utilization

A token is the unit a language model reads and writes: a word, part of a word or a punctuation mark. In English, one token is about three-quarters of a word. Models have limits on how many tokens they can read (the context window) and write, and longer prompts and answers use more of that budget. I counted the tokens in each exported chat with tiktoken, using the o200k_base encoding (the tokenizer used by GPT-4o):

What I learned about tokens and data

  • Unguided prompts spend tokens freely. Prompt 1A ("Explain identity and access management.") is 5 words but produced a seven-section answer of about 1,500 tokens (including page headers in the export). Adding a word limit in 1B cut the answer to about 155 words.
  • Word limits are approximate. The model counts in tokens, not words, which helps explain why "under 150 words" gave about 155 and "trim to 100 words" gave 89 (section 2).
  • Giving the data in the prompt gives exact answers. In Chat 3 I put all the numbers (16, 10, 4, 6) in the prompt, so the model only had to calculate. Its answers (62.5% and 40%) were correct.
  • Memory is also data. ChatGPT used details saved from my earlier chats: it mentioned Care Access Navigator in 1A, named the unguided logo "MoodBuddy" in 5A, and quoted my MoodBuddy program's messages word for word in Chat 4. This was useful, but it is also where the one hallucination came from: an old fact from memory (section 2).

2. AI Hallucination Management

Hallucination identified and corrected

StepDetail
WhereChat 1, the answer to prompt 1A, in a table about my project
What the AI said"RBAC: Five healthcare roles with defined permissions" for Care Access Navigator
Why it is wrongCare Access Navigator has seven roles: Clinician, Nurse, Billing, HR, IT Support, Security Analyst and Vendor (project design document v1.3)
How I caught itI checked every project fact in the answer against my own design document
My correction prompt"In your first answer you said my Care Access Navigator project has five healthcare roles. That is not correct. It has seven roles: Clinician, Nurse, Billing, HR, IT Support, Security Analyst and Vendor. Please correct that table and tell me how you got the number wrong."
AI response"You're correct, and I apologize for the mistake. Your Care Access Navigator project has seven healthcare roles, not five." It rebuilt the table with all seven roles and explained the cause: it "relied on the earlier five-role project scope" from memory and did not check whether it had changed. It also said the permissions would still need to be checked against my access-control matrix.
LessonAn answer can be mostly right and still contain one wrong fact stated confidently. Facts about my own work must be checked against my own documents, and old memory can be out of date.
