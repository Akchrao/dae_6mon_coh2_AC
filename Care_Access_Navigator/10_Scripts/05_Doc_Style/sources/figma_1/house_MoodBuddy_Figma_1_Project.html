1. Frames

The flowchart is organized into three named frame sections, one for each part of the program, so each part can be moved, resized and read as a unit:

FrameWhat it contains
Name and age intakeStart, welcome message, name prompt and check, age prompt and checks, age-range mapping
User record"Name and age found in saved file?" decision: load saved counters or create a new record
Mood check-in loopMood question, negative / non-negative branches, counters and warning, save, continue or quit, end
Figure 2. The live Figma file (November 24, 2026): the "User record" and "Mood check-in loop" frame labels are visible on the right.

2. Images

I added an image to the design using Figma's built-in Unsplash plugin (Resources → Plugins → Unsplash), which places free-to-use Unsplash photos straight onto the canvas. I chose a photo of emoji faces (happy, angry, surprised, laughing and heart emoji) because MoodBuddy is about naming moods, then resized it and placed it next to the algorithm as the MoodBuddy logo.

Figure 3. The photo selected in Figma, with the image toolbar (crop, Edit, Alt text) showing that it is an image layer.

3. Styling

Styling elementHow it is used
Colors by shape typeGreen parallelograms for input and output (prompts, messages); blue diamonds for decisions; beige rectangles for process steps; orange, red and light-green boxes for counters, warnings and resets; a purple diamond for the continue-or-quit choice
Arrow colorsGreen arrows for "Yes" paths and red arrows for "No" paths, so each decision can be followed at a glance
ShapesStandard flowchart shapes: rounded terminators (Start / End program), parallelograms, rectangles and diamonds
Text and fontsLarge title "MoodBuddy Algorithm" and "Flowchart" headings, a numbered list for the 22 algorithm steps with indented Yes/No bullets, small labels inside shapes and on arrows, and the "MoodBuddy" caption under the logo

4. Components

The rubric allows a component made from "a selection of layers or a grouping of objects". I selected the emoji photo and the "MoodBuddy" text (click, then Shift + click) and grouped them with Cmd + G. They now act as one reusable MoodBuddy logo object: a single selection box surrounds both, and they move, resize and copy together.

PartElement
Layer 1Emoji photo (image, from Unsplash)
Layer 2"MoodBuddy" text label
ResultOne grouped object, the MoodBuddy logo (Figure 2: one blue selection box around the photo and the text)
Note: this file is a FigJam board (figma.com/board). FigJam groups objects with Cmd + G; the separate "main component" feature (Option + Cmd + K) is part of Figma Design files, so grouping is the way to build this component here.
