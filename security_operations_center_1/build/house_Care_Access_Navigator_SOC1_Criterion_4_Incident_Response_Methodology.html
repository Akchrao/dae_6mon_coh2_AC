4. Incident Response Methodology

4.1 Initial response protocol: compromised user account

Time from alertStep
0–5 minAcknowledge the alert; open a case in the tracker (status New); note alert IDs and times
5–10 minValidate: raw events, source IP history, user's role and JML status; decide true/false positive
10–15 minSet severity (matrix in 4.3); if SEV-1/2, page IC (and Privacy Officer if ePHI); move case to Triage
15–30 minShort-term containment: disable the account in Keycloak/Entra, revoke sessions and tokens, block the source IP. Preserve logs before any change
30–60 minScope: other accounts from the same IP; records accessed; any privilege changes by this user
OngoingUpdate the case at every step; status report to IC every 30 minutes for SEV-1

Do not: re-enable the account before the password is reset and MFA is enforced; delete or edit logs; contact the user through a channel the attacker may control.

4.3 Escalation criteria and communication

Severity = Impact × Urgency (each 1–3), as in the IR1 playbook CAN-IR-PB-02.

ScoreSeverityStart responseEscalate toCommunication
9SEV-1 Critical15 minIncident Commander; Privacy Officer if ePHIPhone/page now; bridge call; updates every 30 min; executive summary within 4 h
6SEV-2 High60 minTier 2 analyst; IC informedEmail + chat; updates every 2 h
3–4SEV-3 Medium8 hTier 1 ownsCase notes; daily summary
1–2SEV-4 Low5 daysTier 1 ownsCase notes; weekly report

Decision points:

  1. Is the alert a true positive? No → close, tune rule, note in handover.
  2. Was ePHI read, changed or sent out? Yes → SEV-1 and Privacy Officer (HIPAA four-factor breach risk assessment; 60-day notification clock).
  3. Did an attacker get a working session or privileges? Yes → at least SEV-2; page IC.
  4. Is it still happening? Yes → raise urgency by one.
  5. Can Tier 1 contain it within the SLA with their permissions? No → escalate to Tier 2 / IT administrators.

Communication rules: one IC speaks for the incident; facts only, with times in UTC; no patient data in email or chat (use case and record IDs); legal, privacy and communications teams decide on any external notice; every message is logged in the case.
