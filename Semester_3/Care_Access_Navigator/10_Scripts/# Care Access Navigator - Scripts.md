# Care Access Navigator - Scripts

## Purpose
This folder stores scripts used to support the Care Access Navigator lab.

## Folder Structure
- `01_Setup` - Stores scripts used for lab setup and basic configuration tasks.


 This folder can hold scripts used for things like :
- lab setup
- simple automation
- test data generation
- log parsing
- utility tasks


## Notes
- Keep scripts simple and clearly named.
- Do not store passwords, API keys, tokens, or secrets in scripts.
- Use only synthetic and non-production data.
- Add more script folders later only when needed.
