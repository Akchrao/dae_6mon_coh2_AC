# Care Access Navigator - IAM Lab

## Purpose
This folder stores IAM lab documentation and configuration files for the Care Access Navigator project.

## Folder Structure
- `01_Keycloak` - Stores Keycloak configuration notes and realm exports.
- `02_Entra_ID` - Stores Microsoft Entra ID design and lab documentation.

## Keycloak Folders
- `01_Config` - Configuration notes for realms, users, groups, roles, clients, and authentication settings.
- `02_Realm_Exports` - Keycloak realm export files.

## Notes
- Use only synthetic test users and non-production data.
- Do not store passwords, secrets, tokens, or private keys.
- Keep configuration files clearly named and versioned.
- Sanitize files before using them in a public portfolio.
